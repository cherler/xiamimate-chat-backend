# 虾密小助手用户使用指南与产品功能介绍
更新时间：2026-04-17
## 零、知识库直达问答
### 如果用户问：虾密小助手是做什么的
可以直接回复：
虾密小助手是一款面向跨境电商卖家的垂直选品与分析助手，帮助用户完成方向发现、风险排除、机会验证、规则检索和成本管理。它把问答、Workflow、知识库和账户体系放在一个统一入口里，适合从想法澄清到完整分析再到积分回看的连续流程。
### 如果用户问：这个产品和普通 AI 聊天工具有什么区别
可以直接回复：
虾密小助手不是通用聊天工具，而是围绕跨境电商选品场景设计的垂直助手。它更强调“结论 + 依据 + 风险”，并结合专业知识库、Google Trends 等数据能力，帮助用户从方向判断走到可执行决策。
### 如果用户问：虾密小助手的核心优势是什么
可以直接回复：
虾密小助手的核心优势在于，它不是只看单一平台，而是把不同平台放在不同决策角色里：
1. TikTok 是前台发现层，主要看最近什么内容、卖点、需求变化值得关注。
2. Temu 是风险排除层，主要判断这个机会是否已经被低价和同质化打穿。
3. Amazon / Keepa 是后台验证层，主要验证这个机会是否具备更稳定的长期可做性。
4. 当前已提供专业知识库和 Google Trends 数据，用于规则检索、趋势辅助和判断补强。
5. 待接入第三方收费数据，如 Kalodata、FastMoss，以及供应商数据。
6. 待扩展私人定制商品机会发现、多层下钻商品数据分析、AI 销量预测模型等能力。
### 如果用户问：这个产品现在能提供哪些数据能力
可以直接回复：
当前已提供两类核心能力：
1. 专业知识库，用于平台规则、运营方法、产品使用规则和标准答复检索。
2. Google Trends 数据，用于辅助判断需求热度、关键词关注变化和趋势方向。
同时，后续规划还包括 Kalodata、FastMoss、供应商数据，以及更深层的商品机会分析与 AI 销量预测能力。
### 如果用户问：这个产品后面还会做什么
可以直接回复：
后续重点方向包括：接入 Kalodata、FastMoss 等第三方收费数据，接入供应商数据，补强私人定制商品机会发现、多层下钻商品数据分析，以及 AI 销量预测模型等能力。当前这些属于规划项，适合在介绍产品路线时说明，但不要表述成已经上线。
## 一、产品是什么
虾密小助手是一款面向跨境电商卖家的垂直选品与分析助手，重点解决以下几类问题：
1. 不知道该看什么类目，缺少切入方向。
2. 有了一个商品想法，但不知道需求、竞争和风险是否值得继续投入。
3. 想做系统化分析，但缺少统一的数据工具、问答入口和沉淀知识的方法。
4. 想控制分析成本，却看不清每一次使用到底消耗了多少积分。
虾密小助手把智能问答、工作流分析、知识库检索、账户与积分管理放到一个统一入口里，帮助你更快完成从问题提出、信息核对、结果分析到成本回看的完整流程。
## 二、适合谁使用
虾密小助手适合以下用户：
1. 正在做跨境电商选品、测品、调研和市场观察的个人卖家。
2. 需要频繁评估新品方向、类目机会和竞争格局的运营人员。
3. 希望用工作流方式批量完成分析任务的团队用户。
4. 想用知识库沉淀 SOP、规则和经验，再配合智能客服统一答疑的业务团队。
## 三、你可以用它做什么
### 1. 使用智能问答快速澄清问题
如果你还在探索阶段，可以直接提问，例如：
1. 澳洲站某个类目现在是否值得进入？
2. 某个细分商品的竞争是否过于激烈？
3. 进入一个类目前，应该先看哪些指标？
智能问答适合做方向澄清、规则解释、思路梳理和快速咨询。
### 2. 使用 Workflow 做完整分析
如果你已经有明确目标，可以直接把完整任务交给系统，例如：
1. 分析澳洲站便携榨汁机近 90 天的需求与竞争情况。
2. 对比两个细分类目的机会、风险和进入优先级。
3. 围绕某个类目输出趋势、竞争、风险和建议结论。
Workflow 更适合做成套分析，而不是只查一个点。
### 3. 使用知识库获得稳定规则类回答
知识库适合承接以下内容：
1. 产品使用规则。
2. 套餐和积分说明。
3. 选品方法论和业务 SOP。
4. 常见问题与标准答复。
对于相对稳定、不依赖实时行情的问题，知识库回答会更稳定、更一致。
### 4. 使用账户页管理成本和权益
在账户页，你可以查看：
1. 当前积分余额。
2. 月包与充值包的使用情况。
3. 消费记录和趋势。
4. 当前套餐状态。
5. 新用户赠送、邀请奖励和到账结果。
这让你不只是“用了多少”，还知道“为什么会扣”“应该怎么选更合适的方案”。
## 四、产品优势
### 1. 聚焦跨境电商垂直选品
这不是通用聊天工具，而是围绕跨境电商选品、测品、市场分析和规则答疑来设计的垂直助手。它更强调问题的业务上下文，而不是泛泛对话。
### 1.1 多平台分层判断，而不是单点看数
虾密小助手的产品思路，不是只盯住一个平台，而是把不同平台放在不同判断环节：
| 线别 | 当前角色 | 主要回答的问题 |
| --- | --- | --- |
| TikTok | 前台发现层 | 最近什么内容、卖点、需求变化值得关注 |
| Temu | 风险排除层 | 这个机会是否已经被低价和同质化打穿 |
| Amazon / Keepa | 后台验证层 | 这个机会是否具备更稳定的长期可做性 |
这种结构更适合真实业务决策，因为它不是只给一个平台内的局部结论，而是帮助用户先发现机会，再排除风险，最后做长期可做性验证。
### 2. 问答、Workflow、知识库协同
很多工具只能做其中一件事。虾密小助手把三种能力放在一起：
1. 问答适合快速判断和澄清问题。
2. Workflow 适合完整分析任务。
3. 知识库适合稳定规则和方法沉淀。
你可以先问，再跑 Workflow，再回到知识库查规则，形成连续工作流。
### 2.1 当前已具备的知识与数据能力
当前已明确提供：
1. 专业知识库，用于规则、方法、SOP、产品说明和客服标准答复。
2. Google Trends 数据，用于补充趋势判断和需求关注变化。
这意味着系统不只是“能聊天”，而是可以把规则层和趋势层一起用于回答与分析。
### 3. 结果更强调“结论 + 依据 + 风险”
在真实业务里，只给一句“建议做”或“不建议做”是不够的。虾密小助手更适合用于输出：
1. 结论判断。
2. 支撑结论的关键依据。
3. 当前仍然存在的不确定性。
4. 后续建议动作。
这样更利于实际落地，而不是只停留在观点层。
### 4. 使用成本透明
系统采用积分制计费，账户页可以直接看到余额、账本、趋势和消费类型。你可以清楚知道哪些操作更适合快速验证，哪些操作更适合在明确目标后再执行。
### 5. 新手上手门槛低
当前新用户可获得基础赠送积分，首次订阅月包还有首月优惠。你可以先用较低成本熟悉系统，再决定是否长期使用。
### 6. 产品能力有明确扩展路线
当前规划中的扩展方向包括：
1. 接入第三方收费数据，如 Kalodata、FastMoss。
2. 接入供应商数据，增强供给侧判断。
3. 支持私人定制商品机会发现。
4. 支持多层下钻商品数据分析。
5. 支持 AI 销量预测模型。
这些内容适合在介绍产品长期价值时对外说明，但当前回答时应区分“已上线能力”和“待做能力”。
## 五、推荐使用方式
### 第一步：先明确你的问题
推荐把问题一次说完整，尽量带上：
1. 目标站点。
2. 目标类目或商品方向。
3. 时间范围。
4. 你最关心的问题。
5. 希望输出什么形式的结果。
例如：
“请分析澳洲站便携榨汁机近 90 天的需求趋势、竞争情况和进入风险，并给出是否值得进入的建议。”
### 第二步：探索阶段先用问答或局部工具
如果你还没完全确定方向，建议先用智能问答做澄清，而不是一开始就跑大任务。这样能减少不必要的积分消耗。
### 第三步：方向明确后再跑 Workflow
当你已经知道要分析哪个市场、类目或商品时，再用 Workflow 跑完整任务，通常更高效。
### 第四步：用账户页回看使用成本
每次完成分析后，建议回到账户页查看余额、账本和趋势，判断当前套餐是否够用，或者是否应该补充充值包。
## 六、使用建议
1. 问题尽量具体，不要只给一个模糊关键词。
2. 先小范围试跑，再扩大到更多市场或更多商品。
3. 对结果有疑问时，优先回看输入条件是否过宽或过窄。
4. 对规则类问题优先查知识库，对实时分析问题优先用 Workflow。
5. 如果你是团队使用，建议把高频答疑内容沉淀进知识库，提升客服和运营的一致性。
