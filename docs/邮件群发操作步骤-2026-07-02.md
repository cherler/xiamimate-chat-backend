# 邮件群发操作步骤

## 1. 只读获取线上注册邮箱

在本地终端执行：

```bash
ssh your-ssh-host
cd /data/xiamimate-chat-backend
source scripts/load_chat_backend_env.sh
PGPASSWORD="$PG_PASSWORD" psql -h "$PG_HOST" -p "$PG_PORT" -U "$PG_USER" -d "$PG_DB" -Atc "SELECT COUNT(*) FROM app.app_user WHERE NULLIF(BTRIM(email), '') IS NOT NULL AND email LIKE '%@%';"
PGPASSWORD="$PG_PASSWORD" psql -h "$PG_HOST" -p "$PG_PORT" -U "$PG_USER" -d "$PG_DB" -F $'\t' -Atc "SELECT display_name, email, status, created_at FROM app.app_user WHERE NULLIF(BTRIM(email), '') IS NOT NULL AND email LIKE '%@%' ORDER BY created_at DESC LIMIT 20;"
```

## 2. 发布模块到 ECS1

将本次 chat-backend 改动部署到 ECS1 后，重启 chat-backend，使新的后台 API、页面和数据库 bootstrap 生效。服务启动时会自动创建：

- `app.email_campaign`
- `app.email_campaign_recipient`

## 2.1 清理测试邮箱用户

如果注册邮箱的 `@` 后域名包含 `local`、`example`、`test` 等测试关键字，先用脚本预览候选用户。脚本默认只读，不会删除数据：

```bash
cd /data/xiamimate-chat-backend
bash scripts/cleanup_placeholder_users.sh --limit 5000
```

推荐的低风险处理是停用 app 影子用户，并同步停用 Open WebUI 登录源账号：

```bash
cd /data/xiamimate-chat-backend
bash scripts/cleanup_placeholder_users.sh --action disable-app --deactivate-openwebui --execute --limit 5000
```

只有确认这些账号没有需要保留的账本、订单、消息、分析记录时，才考虑物理删除 chat-backend 影子用户：

```bash
cd /data/xiamimate-chat-backend
bash scripts/cleanup_placeholder_users.sh --action delete-app-shadow --deactivate-openwebui --execute --limit 5000
```

执行物理删除前先备份线上数据库和 Open WebUI `webui.db`。不要直接手写 `DELETE FROM app.app_user ...`，因为 app 用户被账本、订单、会话、通知等多张表引用，且 Open WebUI 源用户不处理时可能会再次同步回来。

## 3. 后台发送流程

1. 打开管理后台：`/admin/backoffice`。
2. 填写操作人并完成后台鉴权。
3. 进入“邮件群发”。
4. 使用用户名、邮箱、状态、邮箱验证状态筛选注册用户。
5. 勾选要发送的用户；每封邮件都会按用户逐封单独发送，不会把其他用户邮箱放进收件人列表。
6. 编辑活动名称、邮件主题、纯文本正文和 HTML 正文；正文支持 `{display_name}` 自动替换为用户名，支持 `{email}` 自动替换为收件邮箱。
7. 点击“创建邮件活动”。
8. 确认活动 ID 和收件人数无误后，再点击“确认发送当前活动”。
9. 查看邮件记录中的 `sent_count`、`failed_count`；如失败，查看收件人发送记录和后台审计。
