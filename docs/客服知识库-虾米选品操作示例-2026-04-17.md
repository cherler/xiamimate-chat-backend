## 一、/workflow 实操示例
`/workflow` 适合做完整调研、完整分析、完整报告。
推荐用户在 `/workflow` 后面一次写清楚：
1. 商品或类目。
2. 平台或市场。
3. 时间范围。
4. 希望输出的重点。
### 示例 1：分析单个商品在目标市场的竞争态势
```text
/workflow 帮我分析 婴儿湿巾 在 TikTok Shop 美国市场 的竞争态势，重点看需求趋势、竞争强度、头部卖家特点、价格带和进入风险。
```
### 示例 2：分析某个品类是否值得进入
```text
/workflow 帮我评估 宠物自动喂食器 在 TikTok Shop 美国市场 是否值得进入，给我结论、证据、风险点和建议动作。
```
### 示例 3：做跨市场对比
```text
/workflow 帮我对比 便携榨汁机 在 TikTok Shop 美国市场 和英国市场 的机会差异，重点看竞争格局、价格带和进入优先级。
```
### 示例 4：做趋势与机会调研
```text
/workflow 帮我调研 厨房收纳用品 在 TikTok Shop 美国市场 近 90 天的趋势变化，判断是否存在适合新卖家切入的细分方向。
```
### 示例 5：做报告型输出
```text
/workflow 帮我分析 婴儿辅食工具 在 TikTok Shop 美国市场 的竞争态势，并按“结论、证据、风险、建议”四段结构输出。
```
## 二、/tool 实操示例
`/tool` 适合让系统优先调用现有工具做局部验证，不走完整 Workflow。
当前可用的核心工具包括：
1. `search_knowledge_base`
2. `resolve_candidates`
3. `candidate_pool_stats`
4. `candidate_pool_trends`
5. `candidate_pool_weak_forecast`
6. `top_asin_drilldown`
7. `category_benchmark`
8. `keepa_asin_lookup`
下面是每个工具对应的可直接试用命令。
### 1. /tool 调用 search_knowledge_base 做平台规则检索
```text
/tool 调用 search_knowledge_base 工具，帮我检索 TikTok Shop 美国市场关于 婴儿湿巾、母婴用品、广告投放与合规要求 的知识库内容，并整理成要点。
```
适用场景：
1. 用户先想搞清楚规则和限制。
2. 想先查平台知识，而不是先看商品数据。
### 2. /tool 调用 resolve_candidates 做候选商品池解析
```text
/tool 调用 resolve_candidates 工具，帮我解析 婴儿湿巾 在美国市场的候选商品池，marketplace 用 US，最多返回 30 个候选商品。
```
适用场景：
1. 想先拿到候选商品池。
2. 后面准备继续做统计、趋势、头部商品深挖。
### 3. /tool 调用 candidate_pool_stats 做候选池统计
```text
/tool 调用 candidate_pool_stats 工具，帮我统计 婴儿湿巾 在美国市场候选池的基础表现，marketplace 用 US，window_days 用 30。
```
适用场景：
1. 先看候选池整体规模、价格和基本统计。
2. 不想一上来就跑完整报告。
### 4. /tool 调用 candidate_pool_trends 做趋势诊断
```text
/tool 调用 candidate_pool_trends 工具，帮我分析 婴儿湿巾 在美国市场候选池近 30 天的趋势变化，marketplace 用 US。
```
适用场景：
1. 想知道这个方向近期是升温还是降温。
2. 想先看趋势，再决定要不要深入。
### 5. /tool 调用 candidate_pool_weak_forecast 做弱信号预测
```text
/tool 调用 candidate_pool_weak_forecast 工具，帮我识别 婴儿湿巾 在美国市场候选池中的潜在机会和风险信号，marketplace 用 US，top_n 用 5。
```
适用场景：
1. 想找潜在机会点。
2. 想提前发现风险信号和异常变化。
### 6. /tool 调用 top_asin_drilldown 做头部商品深挖
```text
/tool 调用 top_asin_drilldown 工具，帮我深挖 婴儿湿巾 在美国市场候选池里的头部商品，marketplace 用 US，top_n 用 10。
```
适用场景：
1. 想看头部商品的画像。
2. 想了解卖得好的商品有什么共性。
### 7. /tool 调用 category_benchmark 做类目基准对比
```text
/tool 调用 category_benchmark 工具，帮我对比 婴儿湿巾 在美国市场候选池和所属类目的基准差异，marketplace 用 US，window_days 用 30。
```
适用场景：
1. 想知道这个方向是强于大盘还是弱于大盘。
2. 想看相对优势，而不是只看绝对数值。
### 8. /tool 调用 keepa_asin_lookup 做指定 ASIN 查询
```text
/tool 调用 keepa_asin_lookup 工具，帮我查询 ASIN B08XYZ1234 在美国市场的商品详情，marketplace 用 US。
```
适用场景：
1. 用户已经有明确 ASIN。
2. 想查某个具体商品，而不是整池分析。
3. 本地候选池没覆盖时，做补充查询。
## 三、/tool 组合式实操示例
如果用户想做“先解析、再统计、再深挖”，可以这样描述：
### 示例 1：先拿候选池，再做局部分析
```text
/tool 先调用 resolve_candidates，再调用 candidate_pool_stats 和 top_asin_drilldown，帮我快速判断 婴儿湿巾 在美国市场值不值得继续深挖。
```
### 示例 2：先看趋势，再看风险信号
```text
/tool 先调用 candidate_pool_trends，再调用 candidate_pool_weak_forecast，帮我判断 婴儿湿巾 在美国市场近 30 天是升温还是降温，有没有潜在风险。
```
### 示例 3：先查知识库，再做数据验证
```text
/tool 先调用 search_knowledge_base，再调用 category_benchmark，帮我结合规则和类目基准，判断 婴儿湿巾 在美国市场是否适合新卖家进入。
```
## 四、/web 实操示例
`/web` 适合查最新新闻、政策、平台动态、外部热点。
### 示例 1：汇总当天热点新闻与政策
```text
/web 帮我汇总今天 TikTok Shop 热点新闻和政策，重点看美国市场、电商平台政策、商家入驻、广告和合规变化。
```
### 示例 2：查最新平台政策更新
```text
/web 帮我搜索并总结 今天 TikTok Shop 美国站 最新的入驻、履约、违规和广告投放政策变化。
```
### 示例 3：查行业热点
```text
/web 帮我总结 今天 母婴用品 在 TikTok Shop 美国市场 的热点动态、爆款趋势和舆论关注点。
```
### 示例 4：查竞品或市场情报
```text
/web 帮我搜索 今天 TikTok Shop 美国市场 婴儿湿巾 相关的热点内容、品牌动作和市场讨论，并整理成摘要。
```
